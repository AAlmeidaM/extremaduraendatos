El estado de Extremadura, sistema a sistema

Ocho sistemas —empleo, población, turismo, vivienda, empresas, campo, economía y conocimiento— con su último dato oficial, si está dentro de lo habitual y cuándo se publicó. Abajo, cómo se conectan entre sí. La barra de arriba mueve toda la página a cualquier momento desde 2010.

Cómo se conectan las partes

Cada línea es una relación entre dos partes del sistema. Las continuas están medidas con los datos: se indica cuánto se parecen sus movimientos y con cuánto retraso. Las discontinuas son contables, es decir, relaciones de definición que no hace falta estimar.

Pasa el cursor o toca una línea para ver la relación.
relación medida relación contable El grosor indica cuánto se parecen los movimientos.

Qué es esto

Un gemelo digital del estado de Extremadura: no es tiempo real ni una maqueta del territorio, sino un modelo que se sincroniza cada día con las fuentes oficiales, dice en qué estado está cada parte y muestra cómo se relacionan.
